# 结构图官方形态规范与改造计划

> **为什么有这份文档**
>
> 早先修树状表格 / 矩阵图时，我引用的是一篇 CSDN 文章末尾标着「补充说明（非本页内容）」的段落——
> 那不是官方口径，结果把**层级方向做反了**（树状表格改成"一级分支成行"）。
> 这份文档把每个结构的**官方原文依据**固定下来，改造一律以它为准；
> 官方确实没写的细节，明确标注为「**我方取值**」，不再冒充官方。

## 二、官方未定义的部分（我方取值，写在此处备查）

官方博客是产品介绍性质，以下细节**没有**定义。这些地方由我们取一个合理值，并在代码注释里标注，
**不当作官方规范**：

| 结构               | 官方未定义                                                     | 我方取值                                                                                                                                       |
| ------------------ | -------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| 鱼骨图             | 骨刺在主脊上下两侧的交替顺序、子主题相对骨刺的挂载方向         | 骨刺左右交替；**同一根大骨的子主题对齐成一列**（列 x 取最靠右的取点 + 间隙），小骨从各自取点**水平**连到该列，长短不一但都是清晰的水平线       |
| 时间轴             | 子主题（二级及更深）落在轴的哪一侧；轴的确切几何位置；是否等距 | 子主题挂在刻目上、沿**远离主轴**的方向排成缩进列表；事件沿轴左右（上下）交替，即官方的「水平偏轴」读法                                         |
| 矩阵图             | 行列标题如何设置、单元格如何合并、是否画连线                   | 列＝一级主题（第一维），行＝序号（第二维），同一行**共用基线**；格子在本列内居中（横向偏移钳在列内，纵向偏移不生效）；只用贯穿网格线，不画连线 |
| 树状表格           | 行列方向细则、单元格缩进规则、是否画表格线                     | 从左到右展开：**深度＝列**、同一深度左边缘对齐、每个主题一行；画**贯穿的网格线**；不画连线                                                     |
| 括号图             | 是否画连线                                                     | **不画**父子连线（层级完全由大括号表达，这是括号图的通行规范）                                                                                 |
| 树形图             | 连线形状                                                       | **曲线**枝干（官方只规定布局方向「自上而下／左右／多分支」；曲线分叉读起来才像树，正交折线会和组织架构图混同）                                 |
| 顺时针思维导图     | 起点角度、子节点的扇区大小                                     | 起点＝**右上**（约 1 点钟，−60°），随后按顺时针（角度递增）铺开；同层同半径；子节点扇区收窄到 ≤90°                                             |
| 组织架构图（向上） | 向上版的完全镜像规则                                           | 根在底部、同样"同级横向并列同基线"                                                                                                             |

## 三、现状差距与动作

| 结构               | 现状                                                     | 与官方的差距                                                         | 动作                |
| ------------------ | -------------------------------------------------------- | -------------------------------------------------------------------- | ------------------- |
| 思维导图（平衡）   | 中心居中、一级分支左右交替、曲线连接                     | 基本符合                                                             | 复核                |
| 思维导图（顺时针） | 从**正上方**起铺、同层**同半径环**                       | 起点应在**右上**（顺时针）；子节点应**沿分支射线**贴排，不是同心环   | **重做**            |
| 逻辑图             | 单侧垂直堆叠 + 曲线                                      | 基本符合（根在最左、越右越细）                                       | 复核                |
| 树形图             | 与逻辑图同构，用**正交折线**                             | 官方只规定布局方向；曲线枝干为**我方取值**（折线会和组织架构图混同） | ✅ 改为曲线         |
| 组织架构图         | 根在顶/底、同级同基线、正交折线                          | 基本符合                                                             | ✅ 复核通过         |
| 鱼骨图             | 大骨斜向分列主脊上下、小骨水平、更深层级向右延伸         | 同一根大骨的子主题**错开成阶梯**、小骨仅 17px 几乎看不见             | ✅ 子主题对齐成一列 |
| 时间轴             | 一级主题交替两侧（＝官方的"水平偏轴"）；子主题竖排成一列 | 复核结论：符合官方"轴 + 事件"读法（子主题落位官方未定义）            | ✅ 维持现状         |
| 括号图             | 大括号 ✓，但**额外画了"括号→子节点"的直线**              | 官方/通行规范：括号图**不画连线**                                    | **删连线**          |
| 树状表格           | "行＝一级分支及其后代" + 按子树分组的长横线              | 缺"嵌套块/网格"感，读起来不像表格；且我上轮把方向改反过              | **重做**            |
| 矩阵图             | 一级主题＝列标题，列内**各自纵向堆**、每列一个圆角框     | 缺"行列交叉"：同一行的格子没有对齐，不构成二维网格                   | **重做**            |

## 四、改造顺序（计划表）

按「用户实际使用频率 × 严重程度」排序，一批一验证（每批都跑 `selfcheck`）：

| #   | 批次                    | 内容                                                     | 验证点                       |
| --- | ----------------------- | -------------------------------------------------------- | ---------------------------- |
| 1   | **树状表格**            | 重做：深度＝列、同一深度左对齐、网格线、无连线           | 网格对齐、无重叠、无连线     |
| 2   | **矩阵图**              | 重做：列＝一级主题、行＝序号、同行同基线、网格线、无连线 | 同行对齐、无重叠             |
| 3   | **思维导图（顺时针）**  | 重做：起点改右上、子节点沿分支射线贴排                   | 分支角度递增、子节点不越扇区 |
| 4   | **时间轴（水平/垂直）** | 子主题改沿轴方向排（不再竖排成列）                       | 子主题在主脊同侧、不穿框     |
| 5   | **括号图**              | 删掉"括号→子节点"的连线（原断言同步反转）                | 无父子连线、括号存在         |
| 6   | **鱼骨图**              | 复核子节点与骨刺的贴靠，修掉重叠/穿框                    | 无重叠、无穿框               |
| 7   | **树形图**              | 连线改曲线                                               | 连线为曲线                   |
| 8   | **复核批**              | 平衡思维导图 / 逻辑图 / 组织架构图逐项目视复核           | 与官方形态一致               |

> 每批完成后：更新 `CHANGELOG.md`、同步 `docs/P1-acceptance.md` 与自检断言，并跑完整门槛
> （`typecheck` / `lint` / `format:check` / `verify` / `selfcheck`）。
