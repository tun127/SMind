## 一、逐个对照

| 结构                | 标准长相（参考）                                                                                                                                 | 我们的实现                                                                       | 结论                                         |
| ------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------- | -------------------------------------------- |
| 思维导图（平衡）    | 中心向**左右两侧**均衡分布，子主题向外展开                                                                                                       | 左右交替（第 1 个在右、第 2 个在左），子主题横向展开                             | ✅ 一致                                      |
| 思维导图（顺时针）  | 中心向**四周放射**，子主题沿各自方向继续外扩                                                                                                     | 一级分支按 `-90° + 均分` 铺开；子主题扇区 ≤90°，贴着分支方向                     | ✅ 一致（穿线问题按真实文档再查）            |
| 逻辑图（右/左）     | 中心在一侧，分支**全在另一侧**，逐层递进                                                                                                         | 单侧垂直堆叠 + 曲线连接                                                          | ✅ 一致（用户明确认可）                      |
| 树形图（右/左）     | 同逻辑图，但连线是**直角折线**                                                                                                                   | 单侧堆叠 + `elbow-h` 直角折线                                                    | ✅ 一致                                      |
| 组织架构图（下/上） | 根在顶，同层**水平并列**，连线是**直角 T 形**（父下引竖线 → 横拉 → 落到各子）                                                                    | `elbow-v`：父下 → 中位横线 → 各子上缘                                            | ✅ 一致                                      |
| 时间轴（水平）      | 一条**主轴直线**，节点沿轴依次排列，子主题**挂在各自节点的上下两侧**（短引线）；横版适合大屏                                                     | 主轴 + 刻目（竖引线）上下交替；刻目下的列表用**列脊**（竖脊 + 短横线），严格垂直 | ✅ 一致                                      |
| 时间轴（垂直）      | 一条**竖主轴**，节点自上而下，子主题向**左右一侧**伸出                                                                                           | 竖主轴 + 横向刻目，子主题左右分列                                                | ✅ 一致                                      |
| **鱼骨图**          | 主骨**横线**；一级原因作"大鱼骨"**斜向（约 45°）**分列上下；**子主题沿每根鱼骨继续细分为小骨，逐层向"结果"方向收拢**——小骨是**斜的、与大骨平行** | 主脊 ✓、一级斜骨刺 ✓；但一级分支的子主题是**竖排列表**（列脊）✗                  | ❌ **要改**                                  |
| **矩阵图**          | **二维表**：一级分支排成**行**（行版）或**列**（列版），子主题填入交叉单元格，**网格/框线**                                                      | 表头排成**一行** + 每个表头下面一列格子（≈列版）；用「列脊」连接                 | △ 接近列版，但不是网格线                     |
| 树状表格            | 根在**左上**，一级分支向下排成"行"，子主题向右成单元格，**横竖表格线**                                                                           | 每层固定一列（列 = 层级）+ 列脊连接                                              | △ 接近（层级成列，不是"根在左上、分支成行"） |
| 括号图              | 最左是整体，用**大括号**逐层向右拆解（整体—部分）                                                                                                | 大括号装饰 + 从括号引出短横线到子节点                                            | ✅ 一致                                      |

## 二、子节点（第二层及更深）规格 —— 本轮重点

> 用户反馈：**大结构没问题，子节点的格式不对**。所以这一节专列"子主题怎么摆、怎么连"。

| 结构 | 子节点标准长相（参考） | 我们现在的实现 | 差在哪 |
|---|---|---|---|
| **鱼骨图** | 第二层是**小骨**：从大骨引出，**水平短线、与主骨平行**；第三层及更深**继续在小骨上叠加短横线、向右延伸**；全部直线 | 子主题**竖排**在大骨外侧，用"列脊"（竖脊 + 短横线）连接 | ❌ 方向错：应该是**水平小骨**，不是竖列 |
| **矩阵图** | 子主题**填进单元格**（列 × 行交叉位）；第三层起**在同一格内缩进堆叠**；**没有连线**，靠**网格线 / 底色**分割 | 子主题竖排成一列，用列脊连线 | ❌ 应该是**格内内容 + 网格线**，不该有连线 |
| **树状表格** | 子主题**填进单元格**，逐行自上而下；靠**表格边框与缩进**表达层级；**没有连线** | 每层一列 + 列脊连线 | △ 不该有连线 |
| **时间轴** | 子主题挂在节点旁、**上下展开**，用**短引线**（不用曲线） | 子主题竖排（严格垂直）+ 列脊（竖脊 + 短横线） | ✅ 基本一致（列脊就是"短引线"那一路） |
| **组织架构图** | 子主题在父节点**正下方横向展开**，**直角肘形线** | `elbow-v`（父下 → 横拉 → 各子上缘） | ✅ 一致 |
| **思维导图（平衡/顺时针）** | 子主题沿分支方向**继续向外生长**，曲线 | 向外展开 + 贝塞尔/直线 | ✅ 一致 |
| **逻辑图（右/左）** | 子主题**层层向右缩进、纵向排列** | 单侧堆叠，每层自然缩进一个节点宽 | ✅ 一致（用户认可） |
| **树形图（右/左）** | 同逻辑图，**直角折线** | 单侧堆叠 + 直角折线 | ✅ 一致 |
| **括号图** | 子主题**用括号嵌套**括在更右侧；**没有连线**，层级由括号表达 | 大括号 + 从括号引出短横线到子主题 | △ 多画了短横线（参考说没有连线） |
| **时间轴（垂直）** | 子主题向**左右一侧**伸出，短引线 | 横向刻目 + 子主题左右分列 | ✅ 一致 |

**结论：真正要改的是「鱼骨图」（子节点该是水平小骨）与「矩阵图 / 树状表格」（子节点该是格内内容 + 网格线，不该有连线）。**
「括号图的短横线」是次要项（要不要去掉可以再看）。
