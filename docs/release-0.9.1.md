# SMind 0.9.1

> 本地优先的思维导图软件 · 原生 `.xmind` · 无账号、无服务器
>
> 0.9.1 是**修复与打磨**版：0.9 的主题（AI 直接修改画布）与商业口径（0.9 整版免费，
> 只有「AI 写工具」是 Pro、免费送 30 个写回合）**完全没有变化**。
> 这一版把 0.9.0 发布后暴露的一批缺陷修掉，并把三件事做完：
> **PDF 改矢量**、**边界/概要的空间预留接进全部结构**、**大文档输入不再卡**。

## 修复 · 一批用户能撞到的缺陷

- **关掉 AI 面板后 `Ctrl+Z` 完全没反应**：面板随抽屉卸载时没有收尾回合，撤销被静默挡住
  （画布还因为「回合进行中」一直节流）。现在卸载即收尾，切文档 / 新建 / 恢复也一律复位。
- **多窗口关不掉**：退出流程中确认「关闭」后窗口仍留在原地，像卡死；取消关闭后标记不复位，
  导致之后每次关窗都误走退出分支。新增 `window:close-cancel` 通道修正。
- **快照恢复会把别的文档内容恢复进当前文件**：恢复前按 `snapshotOwnerKey` 校验归属，
  id 不属于本文件即拒绝（数据事故级缺陷）。
- **导出的下划线与删除线**：SVG 曾把删除线画成下划线；PNG / 位图 PDF **完全没画**这两条装饰线。
  现在装饰统一由 `decorationOf` 产出、位图侧补齐装饰线与虚线支持；缺失图片的占位与画布统一。
- **标签拖拽重排时源标签被自己覆盖**（一行删除）。
- **节点属性面板出现双重外壳**（A4 回归）。
- **备注 / 公式 / 代码草稿不随撤销重同步**。
- **UNC 共享盘（`\\server\share`）拖入文件没反应**：`file://` URL 还原路径时被当成相对路径丢掉。
- **配置类文件全部改原子写**（设置 / 自定义主题 / AI 配置 / 自动保存元信息 / 历史与快照索引），
  断电或崩溃不再留下半截文件；导出临时文件改用唯一名（毫秒时间戳会撞名）。
- **`shared` 层一批正确性**：自由摆放的主题之前删不掉也移不动；大小写不敏感匹配对 `İ` 类字符会删错字；
  Markdown 开头的水平线吞掉全文、未闭合围栏丢整块；XML 闭标签改为按名字弹栈；
  zip 解压前按「声明的」未压缩大小拦压缩炸弹；SSE 末尾不带换行的 `data:` 行会丢正文；
  CSS 字符串转义被腰斩。

## 新增 · PDF 改成矢量导出（超大画布自动回落位图）

- 以前导出 PDF 是「把画布栅格化后塞进一页 PDF」——**文字不可选中、放大就发虚、文件还大**。
- 现在主进程用一个隐藏窗口加载**同一份导出 SVG**，再调 Chromium 的 `printToPDF`：
  文字是真字、图形是真矢量，中文交给系统字体（与画布同一批字体，观感一致）。
- 画布超过 Chromium 的页面上限（约 190 英寸）、打印管线抛错、或不在 Electron 里跑时，
  **自动回落高清位图**——导出永远不会因为「想要矢量」而失败。

## 修复 · 边界 / 概要的空间预留接进全部结构

- 之前只有「垂直堆叠」与「组织架构」两个家族为边界/概要留白，**鱼骨图、时间轴、放射图、
  矩阵图、树状表格完全不预留**——给相邻分支加一个边界，边框与标题带会压在大骨 / 刻目 / 格子上。
- 现在预留从「上/下/右」扩成**四向**，并按结构家族决定概要让在哪一侧（多方向结构跟随该支自身方向、
  树状表格让在右侧、上下生长的结构让在下方）；顺带修掉一处同源缺陷：子树占用少算了子节点的预留，
  于是「子树比槽位高、居中之后顶到下一个兄弟」。

## 性能 · 大文档输入不再整图重排

- 编辑文字时每敲一个键都会改变布局的依赖，**万级文档下就是每击键重排整图**
  （重新测量、重新算子树占用、重新拼每一条连线）。
- 现在布局改为**增量**：并行走新旧两棵树，遇到引用相同的子树就整棵剪掉，只看「改动点到根」这条路径；
  每棵子树按「内容 + 尺寸 + 预留」混出版本戳，戳没变就复用测量结果、子树占用、层数与连线；
  只换文字且尺寸没变时，坐标、连线、装饰线、画布级元素整块复用。
- 自检里最关键的一条断言是**「增量结果必须逐个字段等于全量结果」**（14 个结构各跑一遍）。

## 新增 · 许可码批量化与「从文件导入」

- 许可码新增可选**序列号**，签名仍覆盖 payload 原始字节 → **0.8 / 0.9 的旧码完全向后兼容**。
- 新增 `npm run license:issue-batch -- --batch <批次> --count <N>`：**逐张真签**（不是「签一次改字符串」），
  每张签完当场 decode 自查，重复码 / 重复序列号即整批不落盘，输出 UTF-8 BOM 的 CSV 供卡密池导入。
- AI 设置与聊天面板各多一个「**从文件导入…**」入口：选一个含 `SMIND1.…` 的文本文件即可激活
  （长码在聊天 / 邮件里容易被断行，文件形态更稳）。

## 新增 · 自动更新（本版起真正可用）

- 打包版启动 45 秒后做一次后台检查；窗口重新获得焦点且距上次检查超 6 小时会再查一次；
  下载在后台、安装放在退出时（不弹窗打断正在画图的人）；帮助菜单可主动检查并「立即重启安装」。
- 「发现新版本」对话框会显示这版改了什么。
- **免安装版（portable）不支持自动更新**：它每次启动都把自己解压到临时目录，装进去的下一版就没了——
  主动检查时会直接给你「打开下载页」的出口。
- ⚠️ **从 0.9.0 升级到本版需要手动下载**：0.9.0 打包时更新源还没有配置，
  那一版收不到更新提示；**从 0.9.1 起才能自动升级**到之后的新版本。

## 已知限制

- 无代码签名（SmartScreen 提示）、仅 Windows x64；
- 更新源为 **GitHub Releases 直链**（国内拉更新包可能偏慢；R2 国内镜像待有可用支付方式后启用）；
- 免安装版不支持自动更新，请手动下载新版替换；
- 超大画布（约 190 英寸以上）的 PDF 会回落成位图；
- Xmind 8 的 `styles.xml` 不解析。
