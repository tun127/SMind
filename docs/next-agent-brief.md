## 3. 批次 A：官网收尾（4 项，全部在 `D:\smind-site`）

### A1 · 修 hero 脚注断词（**唯一真 bug**，必做）

现状：1440px 下脚注折成两行，且「离线」被拆到第二行、断在词中间。

**定稿做法**（择一并实现）：
- 首选：把脚注拆成"片段 + 分隔点"结构 —— 每个片段 `white-space: nowrap`，
  分隔符为 ` · `；整条**只允许在分隔点处折行**。这样任何宽度下都不会出现"离/线"这种拆词。
- 文案**保留**「除 AI 外全程离线」（这是核心差异化卖点，不许删）。

**验收**：1440 / 1280 / 390 三档下，脚注要么一行，要么在 ` · ` 处折行；
**任何档位都不出现单字被拆到下一行**。

### A2 · 去掉 hero 徽章里的 🚀 emoji（必做）

克制专业基调不使用 emoji 徽章。

**定稿做法**：删掉 🚀，保留文字「v0.9 免费发布 · 源码开放」；
若觉得过素，可在文字前放一个 **6px 的 `--accent` 圆点**（不要换成其他 emoji）。

**验收**：徽章内**零 emoji**；视觉权重不高于原先。

### A3 · 导航「购买 Pro」按钮文字改强调色（必做）

现状：ghost 按钮，文字与背景对比偏弱，Pro 入口几乎"看不见"。

**定稿做法**：仅把该按钮的**文字颜色**改为 `--accent`（`#3B5BDB`）；
按钮底色、边框、尺寸、主次关系**一律不动**（免费下载仍是主按钮）。

**验收**：1440 下能一眼看到 Pro 入口；主按钮仍是实心蓝、权重最高。

### A4 · 给镜像探测加 2.5s 超时（必做，**不是删除**）

现状：`download/setup/index.html` 与 `download/portable/index.html` 里：

```
fetch(MIRROR, { method: 'HEAD' }).then(...).catch(...)
```

**定稿做法**：加 `AbortController`，**2.5 秒**后中止并走 `.catch`（保持回退 GitHub 的既有行为）。
**严禁删除该探测** —— 它是"用户走 OSS（约 1 MB/s）还是回退 GitHub（0.02 MB/s）"的开关；
`dl.smindapp.cn` 实测 `latest.yml` 与安装包均 206、带 `Origin` 的跨域探测 200。

**验收**：弱网/超时下 2.5s 内按钮落到 GitHub 直链；正常网络下按钮为 `dl.smindapp.cn`；
DevTools Network 中**不残留 pending 请求**。

### A5 · 两页同步 + 复测（必做）

两个下载页的令牌、内联 SVG 渐变需与首页一致（前一轮已做，本轮只核对）；
A1–A4 改完在 1440 / 390 两档复跑一次既有自动化体检。

## 4. 批次 B：软件界面「AI 执行动效」（4.6，`d:/Mind`）

> 这是本轮唯一动产品本体的项。它只做**视觉表现**，**不得触碰 AI 执行的事务逻辑**（红线见 4.3）。

### 4.1 三条动效（参数级）

| 时刻 | 动效 | 参数 |
|---|---|---|
| 节点被写入时 | **渐显**：`opacity 0→1` + `scale .98→1` | 120ms，`cubic-bezier(.2,.7,.2,1)` |
| 该节点为"当前执行中" | **描边脉冲**：一圈描边 `opacity .35→.8→.35` 循环 | 1.2s 循环，`ease-in-out`，描边宽 2px |
| 切换到下一步骤 | **高亮转移**：上一步描边收敛到 0，当前步描边起脉冲；配套**视口平滑跟随**到该节点 | 高亮 200ms；视口跟随 ≤600ms，**先快后慢**（不用 spring 过冲） |
| 整回合结束 | **收敛动效**：所有脉冲同时淡出，画布轻微"落定"（`scale 1.005→1`） | 300ms |

### 4.2 实现约束

- 只动 `transform` 与 `opacity`；**不新增依赖、不引入动画库**。
- 动效必须可在**无 AI 的普通编辑操作**下零影响（不改变任何既有绘制路径的性能特征）。
- `prefers-reduced-motion: reduce` 时：**全部关闭**，只保留"节点出现"（不做脉冲/收敛）。
- 不新增设置项（D8）。

### 4.3 红线（违反即返工）

1. **不得改动** AI 执行的事务语义：回合分组、撤销粒度、快照、`inverse` 重放顺序、熔断阈值
   —— 动效只是"贴上去的时间轴表现"。
2. **不得改动**试用计数、`isPro()` 闸门、许可校验、IPC 通道契约。
3. **不得改动**任何对外口径（价格 / 发货方式 / 免费边界 / 退款条款）。

### 4.4 验收（必须交证据，不接受"看起来没问题"）

1. 录一段 10–20s 屏（AI 执行一次写工具回合，含多步、含结束收敛）；
2. 出**三张关键帧截图**：「执行中（步骤 2/共 4）」「写入瞬间」「回合结束」；
3. Electron 实跑：**控制台 0 报错**；DevTools Performance 中该回合**无 >50ms 长任务**；
4. 关掉 `prefers-reduced-motion` 复跑（动效关闭、功能正常）；
5. `npm run typecheck && npm run lint && npm run format:check && npm run selfcheck && npm run verify` **五道全绿**。

## 7. 环境坑（这个项目真实踩过，照做能省半小时）

| 坑 | 应对 |
|---|---|
| GitHub 推送**间歇性**被重置（TCP 通但握手失败） | 重试 3 次、每次间隔 5s；仍失败就告知用户"开一下梯子"，**提交在本地是安全的** |
| 命令行里放**长中文提交信息**会被 shell 解析坏 | 写 `.commit-msg.txt`（已 gitignore）后用 `git commit -F`，用完删除 |
| PowerShell 读文件不带编码会被安全闸拦住 | `Get-Content` 一律带 `-Encoding UTF8`；写回时保留原 BOM 状态 |
| `$home` 是 PowerShell 保留变量 | 别用它当变量名（会报只读错误） |
| 超长内联 PowerShell 命令会被误解析 | 拆成小命令；或把长文本写成文件再读 |
| GitHub Pages 缓存 | 核验必须带 `?v=时间戳`，且推送后等 1–2 分钟 |
