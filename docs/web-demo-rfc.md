# RFC：网页演示版（Web Demo）

- 提出：用户 2026-09-22；级别：**大型（新平台）** —— 按 `docs/dev-plan.md` 需一页说明 + 非目标 + 回滚
- 状态：**待用户批准**（三处需拍板，见 §7）

## 1. 背景与目的（说清"为什么"）

按优先级三个用途：

1. **简历 / 作品集里的链接**（主要动机）：面试官与 HR 不会为了看作品去装 exe → **没链接就没人点**；
2. **用户零安装体验**：下载页加一个「先在线试试」按钮，降低"要不要下载 108 MB"的决策成本；
3. **面试现场**：对方机器通常不让装软件，一个链接最稳。

⚠️ **明确不是为了"面试时演示功能"** —— 远程面试共享屏幕跑**桌面版**才是主战场（真 AI、真文件、真性能）。
网页版的目标是「**点开 30 秒内看懂**」，不是功能对齐。上面这条决定了本文所有取舍。

## 2. 可行性（2026-09-22 实测，不是估计）

| 事实                                     | 数字                                                      | 含义                       |
| ---------------------------------------- | --------------------------------------------------------- | -------------------------- |
| 渲染层 + 共享层的 Node/Electron `import` | **0 处**（全在 `src/main/**`）                            | 核心逻辑天然环境无关       |
| `window.api.*` 调用点                    | **88 处 / 28 个文件 / 65 种方法**                         | shim 面有界                |
| `.xmind` 读写依赖                        | 仅 `jszip`（`shared/xmind/parse.ts:1`、`serialize.ts:1`） | 浏览器直接可用             |
| 内置示例                                 | `samples/` 下已有多份 `.xmind`                            | 可打包进产物，免跨域取 OSS |

## 3. 第一期范围（P1）

**能做到**

- 打开链接即**自动载入内置示例**（面试官零操作成本，这一条比什么都重要）；
- 画布渲染 + 缩放 / 平移 / 折叠展开 / 选中；
- 拖入自己的 `.xmind` 查看（HTML5 drop + `jszip` 解析）；
- 一句"这是在线试用版"的提示条。

**做不到（明确留白，别在页面上钓鱼）**

- **AI 对话**：密钥必须留在桌面版（网页端无法安全保管，且需后端代理过 CORS）→ 入口**不渲染**；
- **许可 / 激活 / 支付**：网页版不做收费相关任何一环；
- **多窗口、最近文件、自动保存、崩溃恢复、快照、诊断导出**：全部空实现；
- **打印与矢量 PDF**：`printToPDF` 是主进程能力，web 端不做（可给 PNG/SVG 导出）。

## 4. 技术方案

- **独立 Vite 构建**（新增 `web/` 配置）：复用 `src/renderer` + `src/shared`，**目标是不改业务代码**；
  预计会有少量「仅桌面」条件分支（这部分要在 PR 里逐处说明）。
- **`window.api` shim**：把 65 种方法分三类
  - **实现**：文件选择 / 下载保存 / 设置 / 主题 / 载入示例 / 导出（约 10 种）；
  - **空实现**：窗口、菜单、诊断、快照、恢复、自动更新（返回 `Promise.resolve(null)` 之类，保证不抛）；
  - **隐藏入口**：AI 与许可相关 UI 不渲染（不是"点了报错"，而是**看不见**）。
- **持久化**：P1 **不落盘**（仅内存），与 §6 的付费边界一致；设置与主题同理（刷新即回默认）。
- **托管**：静态产物放 `smindapp.cn/demo/`（OSS 公共读已具备）。
  ⚠️ **红线**：只动 `demo/` 这个子路径 —— **不得触碰** `latest.yml` / `rt.yml` / 两个 exe / blockmap 同级的任何发布资产。
- **示例文件**：2–3 份打包进产物（不走 OSS，免 CORS 与额外流量）。

## 5. 非目标（写死，防范围漂移）

账号体系 · 云存储与协作 · **AI** · 许可与支付 · 移动端专门优化 · 替代桌面版 · 与桌面版功能对齐。
任何一条要加，都得另开 RFC，不在本文件里"顺手做"。

## 6. 与付费边界的口径（红线）

- 网页版**数据不落盘**（刷新即失），页面显著标注「在线试用版，不会保存你的数据；桌面版可本地保存」；
- **不得**成为"免费完整版"：AI、许可、持久化三项都留在桌面版；
- 导出允许到什么程度 → 见 §7 第 2 条（需用户拍板）。

## 7. 需用户拍板的三件

1. **定位**：只做「体验/演示」（**推荐**）还是要"能真用"？后者会滑向"账号 + 后端 + 常驻成本"的半年工程。
2. **数据边界**：允许导出 `.xmind`（**推荐** —— 导出即体验闭环，但不落盘）还是只允许导出图片？
3. **排期形态**：按 `dev-plan.md` 它属"大型 → 季度版"，**先做 P1 属于一次"受控例外"**（需你明确批准；
   本次不阻塞 0.9.5，也不进 0.9.5 的范围）。

## 8. 分期与工作量

| 阶段       | 内容                                      | 工作量        | 可否上线                  |
| ---------- | ----------------------------------------- | ------------- | ------------------------- |
| **P1**     | 示例自动载入 + 渲染 + 缩放折叠 + 拖入查看 | **1–2 人日**  | ✅ 做完即可当"简历链接"用 |
| **P2**     | 可编辑 + 导入导出 `.xmind` + 导出 PNG/SVG | **+2–3 人日** | ✅                        |
| P3（可选） | 设置/主题落 IndexedDB（刷新仍在）         | +1 人日       | 需先确认不越付费边界      |

## 9. 验收口径（P1 完成时逐条实测）

1. Chrome / Edge / Safari 三个浏览器分别打开链接 → **不点任何东西**就能看到示例脑图；
2. 缩放 / 折叠 / 拖一个节点各一次，无控制台报错；
3. 隐藏入口确认：**页面上找不到 AI 与许可的任何入口**；
4. 刷新后数据确实不残留（与 §6 口径一致）；
5. **反向验证线上资产未被触碰**：`https://dl.smindapp.cn/latest.yml` 的 `version` 仍等于当时线上版本。

## 10. 回滚

删掉 `demo/` 目录即下线。不涉及安装包、渠道清单、官网下载页 → **桌面版更新链路零影响**。
