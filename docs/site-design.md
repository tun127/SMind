> **分工（2026-09-20 约定）**：本文档只负责**方案与规格**（诊断、方向、令牌、参数、验收标准）；
> **代码实现由用户 / 实现方执行**，本角色不落地代码。

> 用于讨论"让它更好看、更高端"。分两块：**官网**（营销页）与**软件界面**（产品本体）。

## 一、诊断：现在不"丑"，是**太像模板**

官网现在的底子：系统字体栈、通用靛蓝 `#4f5be7`、白卡 + 1px 边框、各区块间距平均、
截图直接平铺。这套配置**不会出错，但也不会显贵**。

高端感的来源其实只有三样：**留白、层级、细节一致性**。按影响排序，我看到 6 个具体问题：

| # | 问题 | 为什么影响"贵" |
|---|---|---|
| 1 | **字体没性格**：全站系统字体，中英文混排字重单一 | 字体是廉价/昂贵最直观的差别，成本却最低 |
| 2 | **阴影只有一档**（`0 24px 60px rgba(...)` 用在所有图上），边框也是统一 1px | 层级靠"阴影/边框的**分级**"建立，一档做不到 |
| 3 | **首屏信息密度平均**：徽章、标题、副标题、两按钮、脚注几乎一样重 | 高端页首屏通常只有"一句话 + 一个动作 + 一张图" |
| 4 | **截图裸贴**：圆角 + 单层阴影，没有"窗口感" | 加一个窗口框（顶栏 + 圆角 + 双层阴影）立刻上一个档次 |
| 5 | **功能网格 12 张卡平均用力** | 卡片越多，单卡越不值钱；6 张大的 > 12 张小的 |
| 6 | **全程静止**：无滚动进入、无 hover 反馈 | 少量动效 = 精致感；过多 = 廉价 |

## 二、三个方向，选一个主基调

| 方向 | 气质 | 具体做法 | 适合 |
|---|---|---|---|
| **A · 克制专业**（我推荐） | 贵在"安静" | 更中性的底色、更沉的强调色、大留白、**细边框**、柔和多层阴影、动效极少 | 工具类产品，最稳，且和"本地优先/不订阅"的品牌气质一致 |
| **B · 科技质感** | 视觉冲击 | 深色首屏 + 径向光晕 + 玻璃拟态卡片 + 更多动效 | 想抓眼球、做投放落地页 |
| **C · 品牌个性** | 亲和 | 鲜明品牌色 + 几何插画 + 更活泼的文案 | 面向大众消费者 |

**我的建议：A 为底，借 B 的两个元素**（首屏一层极淡的光晕、窗口截图的深阴影）。
理由是：你的卖点是"数据在本地、买断、离线"，这本身是**冷静、可信**的气质；
走 B 的花哨路线反而会让人觉得"又一个 PPT 产品"。

## 三、可落地清单（含设计令牌与工作量）

> 工作量：★ = 半小时内，★★ = 半天内，★★★ = 需要重排+反复调

| # | 项 | 现在 | 改成 | 工作量 | 收益 |
|---|---|---|---|---|---|
| 1 | **字体** | `-apple-system…` 系统栈 | 英文/数字用 `Inter`（自托管 woff2 子集，约 30KB）+ 中文沿用 PingFang/微软雅黑；标题 `font-weight:650`、`letter-spacing:-0.02em` | ★★ | ★★★ |
| 2 | **颜色令牌** | 靛蓝 `#4f5be7`、底 `#fafbfd` | 强调 `#3B5BDB`（更沉）；底 `#F7F8FA`；笔 `#0F172A`；次级 `#5B6472`；边框 `rgba(16,24,40,.08)` | ★ | ★★ |
| 3 | **阴影分三级** | 一档大阴影 | sm `0 1px 2px rgba(16,24,40,.06)`｜md `0 4px 12px -2px rgba(16,24,40,.08)`｜lg `0 24px 48px -12px rgba(16,24,40,.18)` | ★ | ★★★ |
| 4 | **留白与栅格** | `section{padding:72px 0}`、容器 1080 | `96px 0`、容器 **1120**、卡片 gap 24、正文最大宽度 68ch | ★ | ★★★ |
| 5 | **截图窗口化** | 裸贴 + 圆角 16 | 外面套一层"窗口框"：顶部 3 个圆点 + 细分割线 + 内圆角 12 + `lg` 阴影；再叠一层 1px 内描边模拟玻璃 | ★★ | ★★★ |
| 6 | **首屏重排** | 徽章 + 44px 标题 + 副标题 + 两按钮 + 脚注 | 标题 **52–56px**；副标题砍到一行；**主按钮加大**（高 46px）、次按钮降为文字链；脚注并进副标题下方小字 | ★★ | ★★★ |
| 7 | **功能网格 12 → 6** | 12 张等权卡 | 合并为 6 张（结构 / 富文本·公式·代码 / 导入导出 / 大纲同步 / 安全网 / 多窗口·拖拽手感），每张配一个线性图标 | ★★ | ★★★ |
| 8 | **对比表收敛** | 表格 + `--ok` 绿色标注 | 去掉绿色/灰色对错色，改"强调列浅底 + 其余更淡"；行高加 4px | ★ | ★★ |
| 9 | **滚动动效** | 无 | `IntersectionObserver` 淡入上移 8px、260ms、`cubic-bezier(.2,.7,.2,1)`；`prefers-reduced-motion` 关掉 | ★★ | ★★ |
| 10 | **细节** | favicon 缺失、图片无尺寸占位 | 加 favicon（用软件图标）、图片写 `width/height` 防跳动、OG 卡片图 | ★ | ★★ |

**成本**：1/2/3/4/5/8/10 加起来基本是**改一份 `<style>`**（约 1–2 小时，且能随时回退）；
6/7 需要动 HTML 结构（约 1 小时）；9 是十几行 JS。**零新依赖、零构建步骤**。

## 四、如果你说的是**软件界面**（产品本体）

从最近的截图看，几个可以更"高端"的点（按性价比）：

| # | 观察 | 建议 |
|---|---|---|
| 1 | 工具条图标密集、等权重 | 分三组（节点 / 插入 / 视图）并加**细分隔线**；把低频项收进"更多"溢出菜单 |
| 2 | 底部状态栏 + 标签页信息偏多 | 状态栏只留"文档名 · 节点数 · 缩放"，标签页高度减 2px、去掉多余描边 |
| 3 | 画布与节点配色偏"演示风"（蓝/绿/橙大色块） | 默认主题降低饱和度 8–12%，首层节点保留强调色，三四层用中性色 + 字重区分 |
| 4 | 面板/卡片圆角与阴影不统一 | 统一 8px 圆角 + 一级阴影；面板间距统一 8/12/16 三档 |
| 5 | 空态与加载态朴素 | 空态给一句引导 + 一个主按钮；长耗时操作给骨架/进度 |

> 这些是"看一眼截图"的判断，真要动的话建议**先用一张真实界面并排对比**（改前/改后），逐个确认，别一次全改。

## 六、动态特效清单（"高级"与"花哨"的分界线）

### 先说铁律（违反任一条，动效立刻变廉价）

1. **只动 `transform` 与 `opacity`**（走 GPU 合成）。动 `width/height/top/left` 会触发布局，一卡就廉价。
2. **位移别超过 8–12px**（叙事段除外）；时长：微交互 **160–320ms**，叙事 **400–600ms**。
3. **缓动统一**：`cubic-bezier(.2,.7,.2,1)`（快出慢入）或轻微过冲的 spring；**别用 linear / ease**。
4. **一个页面只留 1–2 个"主角动效"**，其余全部克制 —— 这条是分水岭。
5. **首屏动效 1 秒内结束**，别让人等；并尊重 `prefers-reduced-motion: reduce`（直接关掉）。
6. **不用动画库**（GSAP / Framer）。CSS + `IntersectionObserver` + `requestAnimationFrame` 就够，零依赖、零构建。

### A. 官网可用清单（按"显贵"排序）

| # | 特效 | 怎么做 | 成本 | 显贵度 |
|---|---|---|---|---|
| A1 | **首屏加载序列**：徽章 → 标题 → 副标题 → 按钮 → 截图，各差 80ms 依次淡入上移 | 纯 CSS `animation-delay` | ★ | ★★★ |
| A2 | **滚动进入**：元素进入视口时淡入 + 上移 8px | `IntersectionObserver` 加类名；或 CSS `animation-timeline: view()`（新浏览器，留 JS 退化） | ★ | ★★ |
| A3 | **粘性叙事段**（最值钱）：进入 AI 区时截图**钉**在视口，右侧三步文案随滚动切换（选中节点 → AI 给计划 → 画布自动成三层） | `position:sticky` + 三步文案 + 截图 3 帧 crossfade；**不需要录视频**，用 3 张静态帧即可 | ★★★ | ★★★★ |
| A4 | **顶部滚动进度细线** | `scroll` + `rAF`（或 `animation-timeline: scroll()`） | ★ | ★★ |
| A5 | **卡片 hover 微浮**：上浮 2px + 阴影升一级 + 边框提亮 | 纯 CSS | ★ | ★★ |
| A6 | **hero 光斑跟随光标**：一层 `radial-gradient` 跟着鼠标极缓移动 | `mousemove` + rAF 节流 + `transform` | ★★ | ★★ |
| A7 | **真实数字计数**：14 种结构 / 21 个兼容样本 / **2753 项自检** —— 滚到才滚数字 | `IntersectionObserver` + rAF 插值 | ★★ | ★★★ |

> A7 特别值得做：**用真实数字**（都是仓库里的实测值，不是编的），比任何炫技都更能打动人。

### B. 软件界面（这里动效是**产品体验**，比官网更值钱）

| # | 特效 | 说明 |
|---|---|---|
| B1 | **AI 执行过程**：节点写入时渐显 + 描边脉冲；每步高亮 + 视口平滑跟随；整回合结束收敛动效 | 这是核心卖点"边执行边可见"的可视化升级，最该做 |
| B2 | **拖拽反馈**：吸附预测线生长、落点指示器展开动画 | 手感直接变"贵" |
| B3 | **面板/标签**：开合用带轻微过冲的 spring；标签重排用 FLIP 动画（已有拖拽重排，补个过渡） | 细节精致度 |
| B4 | **撤销/重做**：内容轻微回弹（60–80ms） | 让"可撤销"这件事被感知到 |
| B5 | **大文档打开**：骨架屏 + 进度条（别只转圈） | 观感与信任 |

### C. 我建议的组合（只做 4 件，已经够"高级"）

1. **A1 首屏加载序列** —— 第一印象，成本半小时
2. **A3 粘性叙事段**（3 帧静态图）—— 把"AI 一句话改整张图"讲清楚，最有说服力
3. **A5 卡片 hover + A4 滚动进度线** —— 全程的精致感
4. **A7 真实数字计数** —— 2753 项自检 / 21 个样本，可信度直接拉满

**不做的**：背景粒子、3D 翻转、打字机、全屏视差（这些都是"廉价感"重灾区）。

### D. 素材成本说明

- A1/A4/A5/A7：**不需要任何素材**，纯代码
- A3：需要 **3 张同尺寸截图**（同一个文档的三种状态：只有根节点 → 出现 AI 计划 → 三层结构成型）。我可以先做"用现有截图 + crossfade"的占位版，等你有素材再换
