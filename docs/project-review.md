### C. 拖拽还能继续优化（按价值排序）

| # | 优化点 | 现状 | 建议 |
|---|---|---|---|
| C1 | **非法落点毫无反馈** | 拖到自己 / 自己的后代 / 自己的父级身上时，既无提示、松手也不动，容易被当成「卡死」 | 禁止光标 + 一句可读提示（「不能落到自己或自己的子主题里」） |
| C2 | **多选拖到主题身上无反馈** | 多选只支持同级插入，现在是「静默不动」 | 明确提示「多选拖拽只能插到同级之间」 |
| C3 | **「追加子主题」的落点** | 给已有子节点的主题追加子主题，只能落在**父主题本体**上；落在它**最后一个子节点之后**（很自然的动作）会判成同级插入 | 把「子节点列末端之外」也认成该主题的子落点 |
| C4 | **窗口常量是固定像素** | `GROWTH_REACH=84`、`SIBLING_REACH=29`、`DROP_HYSTERESIS=14` 都是屏幕像素；缩放到 50% 时等效世界距离翻倍，手感会变 | 按 `zoom` 折算成世界单位 |
| C5 | **节点内部的插值分区仍是 28%** | 成熟实现（simple-mind-map 的 Drag 插件）是「本体内部一律算成为子主题、**缝隙**才算插前 / 后」；我们保留了 Xmind 式的上下缘 28% | 对齐后可去掉 `zoneOf` 旧模型，判定只剩一套 |
| C6 | 边界 / 概要不可拖动 | 只有关系线支持线身拖动改弯度 | 视需要再定 |

### D. 已知限制（非本轮引入，文档已记录，仅备查）

- 导出 PDF 是**位图 PDF**，非矢量
- SVG 导出里部分标记图形（笑脸 / 箭头等）简化为同色圆点

- 亿图 `.emmx` 专有二进制格式**只能提取文字**，层级不可还原
- 渲染层产物 2.46 MB（含 KaTeX），未做按需懒加载
- 渲染进程未设置 CSP
- 打包无代码签名（首次运行会提示「未知发布者」）、无自动更新
