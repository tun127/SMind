# SMind 0.8.0

> 本地优先的思维导图软件 · 原生 `.xmind` · 无账号、无服务器

0.8 的主题是**把 AI 请进软件里**。

## 新增：内置 AI 助手（免费，只读）

- **聊天面板**：右侧边栏，用自然语言聊当前这份导图；流式输出，随时可「停止生成」。
- **它会自己翻看导图**：搜索主题、读某个分支的结构、看文档规模、读你当前选中的主题；
  面板里用小标签显示「它翻看过什么」。
- **回复里的标题可点**：点一下就在画布上选中并居中。
- **对话按文档保留**：存在 `%APPDATA%\SMind\chat\`，**不写进 `.xmind`**；没保存过的新文档只在内存里，关掉即弃。
- **只读**：这一版刻意不改你的画布——零数据风险。
- 支持任何 **OpenAI 兼容**接口：DeepSeek / OpenAI / 通义 / 智谱 / Kimi / 本地 Ollama。
  需要模型支持**函数调用**；不支持的模型会自动降级成纯对话并提示。

原有三个「会改画布」的 AI 功能（一键生成导图 / 扩写子主题 / 润色标题）照旧可用，
并收成了聊天面板里的入口（仍先预览、确认后才写入）。

## 修复

- 点「停止生成」后界面崩溃（`Cannot read properties of undefined`）。
- 错误边界下**窗口关不掉**（此前只能去任务管理器）、「重新加载界面」点了没反应。

## 安装

| 方式 | 文件 |
|---|---|
| 免安装（推荐） | `SMind-0.8.0-x64-portable.exe`，双击即用 |
| 安装版 | `SMind-0.8.0-x64-setup.exe`，会注册 `.xmind` 文件关联 |

**首次运行**会出现「Windows 已保护你的电脑 / 未知发布者」——本软件没有代码签名证书，
点「**更多信息**」→「**仍要运行**」即可。运行要求：Windows 10 / 11，64 位。
