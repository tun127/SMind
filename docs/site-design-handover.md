## 0. 一页速览

| 项 | 结论 |
|---|---|
| **目标** | 让官网"更贵"、软件界面"更精致"；**不改变任何对外承诺口径**（价格 / 发货方式 / 免费边界） |
| **基调（默认）** | **方向 A「克制专业」**，借 B 的两个元素：首屏一层极淡光晕、截图用深阴影 |

## 1. 诊断（为什么"不够贵"）

官网现状：系统字体栈、通用靛蓝 `#4f5be7`、白卡 + 1px 边框、各区块间距平均、截图裸贴。
**不出错，但不显贵。** 六个具体缺口（按影响排序）：

1. 字体无性格（中英混排字重单一）
2. 阴影/边框只有一档 → 层级立不起来
3. 首屏信息密度平均（徽章/标题/副标题/按钮/脚注几乎同权）
4. 截图裸贴（缺"窗口感"）
5. 功能网格 12 张卡平均用力 → 单卡不值钱
6. 全程静止（无进入动效、无 hover 反馈）

## 2. 设计令牌（规格，可直接抄进实现）

### 2.1 色彩

| 令牌 | 值 | 用途 |
|---|---|---|
| `--bg` | `#F7F8FA` | 页面底色（比现在的 `#fafbfd` 更中性） |
| `--card` | `#FFFFFF` | 卡片底 |
| `--ink` | `#0F172A` | 主文字 |
| `--muted` | `#5B6472` | 次级文字 |
| `--accent` | `#3B5BDB` | 强调色（比 `#4f5be7` 更沉、更"贵"） |
| `--accent-dark` | `#2F49B8` | 按钮 hover |
| `--ok` | `#0E9F6E` | 成功态（仅少量使用） |
| `--line` | `rgba(16,24,40,.08)` | 边框（用透明度而非实色，深浅底都自然） |

### 2.2 阴影（三级，替代现在的"一档大阴影"）

| 令牌 | 值 | 用途 |
|---|---|---|
| `--shadow-sm` | `0 1px 2px rgba(16,24,40,.06)` | 卡片常态 |
| `--shadow-md` | `0 4px 12px -2px rgba(16,24,40,.08)` | 卡片 hover、下拉 |
| `--shadow-lg` | `0 24px 48px -12px rgba(16,24,40,.18)` | 截图窗口、hero |

### 2.3 圆角与间距

| 项 | 值 |
|---|---|
| 圆角 | 按钮 10px / 卡片 16px / 截图窗口外框 16px·内图 12px / 徽章 999px |
| 区块垂直间距 | `padding: 96px 0`（原 72px） |
| 内容容器 | `max-width: 1120px`（原 1080px） |
| 栅格间距 | 卡片 gap 24px；卡片内边距 28px |
| 正文行宽 | 最大 68ch（超过就难读） |

### 2.4 排版

| 项 | 规格 |
|---|---|
| 字体栈 | `Inter, -apple-system, "PingFang SC", "Microsoft YaHei", sans-serif`（**不引字体文件时**：删掉 Inter，仅用系统栈） |
| 标题 | `font-weight: 650`；`letter-spacing: -0.02em`；`line-height: 1.25` |
| 首屏标题 | 52–56px（移动端 32px） |
| 区块标题 | 30–32px |
| 正文 | 15.5–16px / `line-height 1.7` |
| 按钮文字 | 15px / 600 |

### 2.5 动效（统一参数，全部条目共用）

| 项 | 规格 |
|---|---|
| 只允许动 | `transform`、`opacity`（禁止 width/height/top/left） |
| 时长 | 微交互 **160–320ms**；叙事 **400–600ms** |
| 缓动 | `cubic-bezier(.2,.7,.2,1)`（统一，不许出现 `ease`/`linear`） |
| 位移 | ≤ **12px**（叙事段除外） |
| 无障碍 | `@media (prefers-reduced-motion: reduce)` 下**全部关闭** |
| 首屏 | 全部动效 **1s 内结束** |

## 3. 官网改造清单

> 每条给：**目标 → 现状/改成 → 参数 → 结构建议 → 退化 → 验收**

### P0（建议首批，全部零素材，约 2–3 小时）

**3.1 令牌替换**（一次性，全局生效）
- 参数：§2.1–2.5 全部令牌
- 结构建议：只改样式层，**不动任何 DOM 结构**；这一步做完就能整体看到"气质变了"
- 退化：无（纯 CSS 变量）
- 验收：页面上不出现旧靛蓝 `#4f5be7`；边框不再用实色 `#e6e9f2`

**3.2 首屏重排**
- 目标：让首屏只讲"一句话 + 一个动作 + 一张图"
- 改成：标题 52–56px；副标题**砍到一行**（约 34 字以内）；主按钮加大到高 46px；副按钮降级为**文字链**；
  「免安装 · 约 108MB · Windows 10/11 · 买断制」这行脚注**并入副标题下方的小字**（字号 13px、`--muted`）
- 结构建议：徽章 → 标题 → 副标题 → 按钮组 → 脚注 的**视觉权重依次递减**，不要再出现第三个同权按钮
- 退化：窄屏（<520px）标题降 32px、按钮全宽
- 验收：首屏在 1440×900 下一屏内能看到"标题 + 主按钮 + 截图顶部"

**3.3 截图窗口化**（把裸截图变成"产品实拍"）
- 改成：外层"窗口框"（顶部 3 个圆点 + 细分割线）＋内图 12px 圆角＋`--shadow-lg`；
  外框加 1px `--line` 内描边模拟玻璃边
- 参数：窗口框内边距 0；圆点直径 10px、间距 8px、色 `rgba(16,24,40,.12)`；顶栏高 32px
- 结构建议：外层容器 + 顶栏 + `img`（`img` 用 `display:block` 消掉基线间隙）
- 退化：移动端隐藏顶栏圆点（省高度）
- 验收：截图像"一张截图放在窗口里"，而不是"图片直接贴在页面上"

**3.4 卡片 hover 微浮**
- 参数：`translateY(-2px)` + 阴影 `--shadow-sm` → `--shadow-md` + 边框提亮到 `rgba(16,24,40,.14)`；时长 200ms
- 退化：触屏设备无 hover，正常；`reduced-motion` 下只留阴影变化
- 验收：鼠标划过卡片有"抬起来"的感觉，但**没有位移超过 2px**

### P1（第二批，约 3–4 小时）

**3.5 功能卡片 12 → 6**（合并建议，见下表）
- 目标：卡片越少，单卡越值钱；每张配一个线性图标
- 结构建议：仍是 3 列（窄屏 2 列 → 1 列），每张卡的描述控制在**一行半**

| 合并后（6 张） | 吸收原卡 |
|---|---|
| 14 种结构（9 大族） | 原「14 种结构」 |
| 富文本 · 公式 · 代码块 | 原「富文本」+「LaTeX 公式」+「代码块」 |
| 图片 / 附件 / 导入导出 | 原「图片与附件」+「导入导出」 |
| 大纲双向同步 | 原「大纲双向同步」 |
| 安全网（自动存档 · 快照 · 撤销） | 原「安全网」 |
| 多窗口 · 拖拽手感 · 视角锁定 | 原「多窗口多标签」+「拖拽手感」+「视角锁定」 |

> 被合并掉的「搜索·筛选·统计」建议移入 §3.6 的对比表下方一行小字，不单独占卡。

**3.6 滚动进入动效**
- 参数：进入视口 20% 触发；`opacity 0→1` + `translateY(8px)→0`；260ms；同组子项错开 60ms
- 结构建议：按区块（section）挂类，子项用 CSS 变量 `--i` 控制延迟；触发只加一次类，不反复回放
- 退化：不支持时元素直接显示（**先写"默认可见"，再用 JS 加类做动画**，别反过来）；`reduced-motion` 下不启用
- 验收：滚动时元素依次出现；快速滚动到底部不会出现"空白未出现"的元素

**3.7 顶部滚动进度线**
- 参数：高 2px；`--accent` 渐变到透明；`transform: scaleX()` 驱动（不要动 width）
- 退化：无（渐进增强）
- 验收：进度与滚动位置一致，且**不引起横向滚动条**

**3.8 真实数字计数**
- 内容（全部为仓库实测值，不要编）：**14 种结构**、**21 个兼容样本**、**2753 项自检、107MB 体积**
- 参数：进入视口触发一次；插值 800ms；只在整数位滚动；数字用 `font-variant-numeric: tabular-nums` 防抖动
- 退化：`reduced-motion` 或脚本未执行时**直接显示最终值**
- 验收：数字肉眼看着"滚上去"而不是"跳变"；不会因宽度变化导致文字抖动

**3.9 对比表收敛**
- 改成：去掉绿/灰"对错"色；改为"SMind 列浅底 + 其余列更淡"；行高 +4px；表头去掉底色改用细线
- 验收：表格不再像"考试评分表"

### P2（加分项）

**3.10 粘性叙事段（依赖素材，最重要的一条）**
- 目标：把「AI 一句话改整张图」讲清楚
- 结构：左（或上）侧截图 `position: sticky` 钉住；右侧三步文案随滚动切换高亮；截图三帧 `opacity` crossfade
- 三步文案方向：① 选中一个乱糟糟的节点 → ② AI 给出执行计划 → ③ 画布上三层结构成型
- 素材要求：**3 张 2560×1454 同尺寸截图**（同一文档、同一缩放、同一主题）
- 退化：移动端退化为"三张图上下排列 + 各配一句文案"（不做 sticky）；无素材则整项延后
- 验收：滚动时截图不跳位（钉住不抖）；三帧切换处无闪白

**3.11 hero 光斑跟随光标**
- 参数：一层 `radial-gradient` 圆形高光，跟随鼠标移动，`translate3d` 位移；rAF 节流；上限 `±40px`
- 退化：触屏不启用；`reduced-motion` 不启用
- 验收：几乎察觉不到"在动"，但画面比静止时有层次

**3.12 favicon 与分享卡**
- favicon 用软件图标（已有源图）；补 OG 卡片图（1200×630，标题 + 一句卖点 + 图标）
- 验收：链接分享到微信/QQ/推特有缩略图

## 4. 软件界面（产品本体）——诊断与规格级建议

> ⚠️ 这一块的定稿流程建议：**先做"改前/改后并排对照"**（各一张同场景截图），逐条确认后再动手。
> 不要一次全改 —— 界面动效牵扯用户已有文档的视觉预期。

| # | 现状问题 | 建议规格 | 优先级 |
|---|---|---|---|
| 4.1 | 工具条图标密集、等权重 | 分三组（节点 / 插入 / 视图），组间加 1px 细分隔线；低频项收进"更多"溢出菜单 | P1 |
| 4.2 | 底部状态栏 + 标签页信息偏多 | 状态栏只留"文档名 · 节点数 · 缩放"；标签页高度减 2px、去多余描边 | P1 |
| 4.3 | 节点配色偏"演示风"（大色块） | 默认主题降低饱和度 8–12%；首层节点保留强调色，三/四层改用中性色 + 字重区分 | P1 |
| 4.4 | 面板圆角/阴影不统一 | 统一 8px 圆角 + 一级阴影；间距统一 8 / 12 / 16 三档 | P2 |
| 4.5 | 空态与加载态朴素 | 空态给"一句引导 + 一个主按钮"；长耗时操作给骨架屏/进度条 | P2 |
| 4.6 | **AI 执行过程可动效化（最值钱）** | 节点写入渐显 + 描边脉冲（120ms）；每步高亮 + 视口平滑跟随；整回合结束收敛动效（300ms） | **P0** |
| 4.7 | 拖拽反馈 | 吸附预测线"生长"动画；落点指示器展开（160ms） | P1 |
| 4.8 | 撤销/重做无感 | 内容轻微回弹（60–80ms），让"可撤销"被感知 | P2 |

> 4.6 是唯一建议优先做的：它是核心卖点"边执行边可见"的可视化升级，投入产出比最高。

## 5. 明确不做（边界，防止范围蔓延）

- 背景粒子 / 星点 / 流光
- 3D 翻转、卡片倾斜跟随
- 打字机文字（廉价重灾区）
- 全屏视差滚动（hero 以外）
- 截图无限上下浮动
- 引入任何动画库（GSAP / Framer / Lottie）
- 任何改变**价格、发货方式、免费边界、退款条款**的表述（这些有台账，视觉改版不得触碰）

## 6. 验收标准（整体，改完逐条过）

| 类别 | 标准 |
|---|---|
| 性能 | 滚动 60fps（DevTools Performance 无 >50ms 长任务）；**CLS 不退化**；首屏动效 1s 内结束；不出现横向滚动条 |
| 无障碍 | `prefers-reduced-motion: reduce` 下无任何动画；正文对比度 ≥ 4.5:1；键盘焦点可见（`outline`） |
| 一致性 | 同类元素用同一参数（时长/缓动/圆角/阴影）；全站不出现旧令牌（旧靛蓝、实色边框） |
| 视觉对比 | 改前/改后**同尺寸并排截图**留档（1440×900 与 390×844 各一份）；作者自评"层级是否更清楚" |
| 内容 | 文案未变（若有变，必须走台账口径：价格 / 发货 / 免费边界） |

## 9. 风险与回退

| 风险 | 回退方式 |
|---|---|
| 主基调不合口味（A/B/C 选错） | 只改"令牌层"（§2），结构不动，10 分钟换风格 |
| 动效影响性能 | 每项动效互相独立、可单独关闭；全部动效集中在少量类名下 |
| `animation-timeline` 浏览器支持不全 | 一律保留 IntersectionObserver 退化路径；**先用 JS 方案，不用新特性冒进** |
| 视觉改版误改口径 | 改动仅限样式与结构；文案变更必须走 `docs/ops.md` 台账 |
| 改完"更花但不更贵" | 执行 §5 的"不做清单"；出现犹豫就删动效，而不是加 |

### 11.1 建议微调（按优先级，均属细节不属返工）
