# SMind 0.9.0

> 本地优先的思维导图软件 · 原生 `.xmind` · 无账号、无服务器

0.9 的主题是**让 AI 动手**：AI 助手从「只读聊天」升级为「写工具 agent」——
用自然语言直接修改导图，整轮改动一步撤销。

## AI 写工具 agent（Pro 功能，免费送 30 个写回合）

用一句话让 AI 整理、扩写、重排当前导图：

- **18 个写工具直接操作画布**：改标题、插入/删除子树、单个/批量移动、折叠
  （思维导图可只收起某一侧）、写备注 / 代码 / 公式，以及关系线 / 边界 / 概要 / 标记 / 标签；
  全部走与用户快捷键相同的编辑管道，AI 改不出非法状态。
- **安全网一套做齐**：整轮改动算**一步撤销**（`Ctrl+Z` 一次全回来）；动手前**自动存版本快照**；
  回合中锁定撤销 / 重做，`Esc` 随时停止（已执行部分保留、可撤）；超上限熔断；
  删除分支等破坏性操作先确认（可记住选择，随时在 AI 设置里恢复）。
- **边执行边叙述**：多步任务实时在聊天面板滚动播报；被改的节点闪亮两下、视口跟到改动处；
  工具调用显示为可展开条目。
- **会自己探查**：搜索主题、读分支结构、看文档规模；被折叠收起的内容会如实标注
  「画布上当前看不到」，模型不会把看不见的分支当成不存在。
- 需要模型支持**函数调用**（DeepSeek / OpenAI / 通义等均可）；不支持的模型自动降级为纯对话。

**试用与解锁**：免费送 **30 个写回合**；超出后需要 **Pro 许可码**解锁
（Ed25519 签名、**本地离线验证**，无账号、无在线激活）。Pro 为**买断制**，购买渠道即将开放。

0.7 的全部功能 + AI 只读聊天（问答 / 分析 / 润色）**永久免费，永不收回**——本版继续免费。

## 新增与改进

- **按侧收起（思维导图）**：平衡 / 顺时针结构的中心主题左右各一颗折叠点，可只收起某一侧；
  折叠徽标跟随分支方向；AI 也能使用（`setCollapsed` 带 `side`）。
- **统计与骨架标注「已收起」**：统计面板与 AI 骨架摘要标出被折叠收起的节点数（内容仍在文档里）。
- **导出的标记图标矢量保真**：SVG / PNG 导出的标记图标改用矢量数据绘制
  （数据来自 lucide-react，ISC 许可），与画布同款，不再简化成圆点。
- **14 种结构逐个对齐 Xmind 官方定义**：树状表格（深度=列+贯穿网格线）、矩阵图（二维网格）、
  括号图（大括号表达层级）、鱼骨图小骨对齐、顺时针起点改右上等。
- 一批折叠相关修复：大纲 / `Ctrl+/` 在按侧收起时的动作口径、跨侧拖动自动展开、
  鱼骨图折叠后不再留孤线。
