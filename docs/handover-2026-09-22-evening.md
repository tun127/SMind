## 5. 这一轮踩过的坑（别重踩）

| 坑                     | 事实                                                                                                           |
| ---------------------- | -------------------------------------------------------------------------------------------------------------- |
| 冻结打包会覆盖线上资产 | `npm run dist` 默认写 `release/`；冻结版必须 `--config.directories.output=release-frozen-0.9.x`                |
| 测试构建会被上传       | `"dist"` 脚本**没有** `--publish`（默认不是 never）→ 必须显式 `--publish never`                                |
| 忽略规则写死了一次     | `.gitignore` 里 `release-frozen-0.9.3/` 是一次性的；已改 `/release-frozen-*/`（否则 0.9.4 的 500 MB 会漏进去） |
| 手写类型声明           | 给 `scripts/lib/*.mjs` 加导出**必须同步改同名 `.d.mts`**，否则 `typecheck` 报 TS2305（运行时不受影响，极易漏） |
| 命令行喂文件           | 必须用**绝对路径**（相对路径必弹「文件路径无效」，已登记 P3）                                                  |
| 探针读早了             | 文件加载有延迟：转交文件后要等几秒再读，否则会误判成"没打开"                                                   |

## 6. 环境事实（排障用）

- **用户数据目录**：`%APPDATA%\SMind\`（`history.json` 最近文件、`settings.json`、`license.json`、`instance.json` 单实例锁）
- **主进程日志**：`%APPDATA%\SMind\logs\main-YYYY-MM-DD.log` —— ⚠️ 时间戳是 **UTC**（比本地早 8 小时）
- **开发版**：`npm run dev`（Vite 5173；应用自己会开 CDP `9222`，仓库探针 `scripts/verify/*.cjs` 直接连它）
- **单实例锁**：dev 与打包版共用同一 userData → 再开一个实例只会"把文件转交给已有窗口并退出"
  （日志有 `single-instance` 行，这是正常行为，不是崩溃）
- **OSS 桶权限（2026-09-22 匿名实测）**：可读、**不可写 / 不可删 / 不可列举** —— 公共读是自动更新必需的
  （客户端不带凭据），安全中心对"公共读"的扣分可以接受；真正的风险在 AK 泄露，不在桶公开。
