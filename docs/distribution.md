# 分发说明（把 Mind 发给别人）

> 结论：**可以直接把免安装版发给别人**——单文件、自带运行时，双击即用，
> 不需要装 Node、不需要管理员权限、不需要联网。
> 本文记录分发时要交代的事、以及已实测确认的行为。

---

## 一、可以直接复制发送的一段话

> **用法**：双击 `Mind-0.1.1-x64-portable.exe` 即可，免安装。
>
> 1. 首次运行若弹出**「Windows 已保护你的电脑 / 未知发布者」**（本软件没有代码签名），
>    请点「**更多信息**」→「**仍要运行**」。
> 2. 若杀毒软件拦截，请加为信任（未签名的程序偶尔会被误报）。
> 3. 需要 **Windows 10 / 11 64 位**；Mac / Linux 用不了。
> 4. 文件约 **107 MB**，微信 / 邮件可能发不出去，用网盘更稳。

---

## 二、已实测确认的行为（不是推测）

| 事项 | 实际行为 |
|---|---|
| **启动过程** | 免安装版每次启动会先把程序解压到 `%TEMP%`（约 300 MB）再运行，退出时自动清理 → **比安装版慢几秒**（本机实测约 6 秒出窗口） |
| **数据存哪儿** | **运行的那台机器的 `%APPDATA%\Mind`**：设置、主题、最近打开、版本快照、自动存档、AI Key 全在这里。所以它"免安装"，但**不是"零痕迹"**；换电脑要重新配 AI Key |
| **文件存哪儿** | 首次保存默认落在该机器的「**文档 / 思维导图**」目录 |
| **AI 功能** | 需要使用者**自备 API Key**（软件不提供额度）；**其余功能全程离线**，不点 AI 就不会有任何网络请求 |
| **改名 / 移动** | 可以随意重命名和挪位置：解压目录名不由文件名决定 |
| **与安装版共存** | 同一台机器上装了安装版又用免安装版，两者**共用同一份配置与最近文件**（都在 `%APPDATA%\Mind`） |
| **程序名冲突** | 应用名就叫 `Mind`，若对方机器上已有别的软件也用 `%APPDATA%\Mind`，配置会互相覆盖（概率很低，但值得留意） |
| **单实例** | 同时只能开一个：再双击一次会因"已有实例"直接退出（看起来像没反应） |

> 权限：打包配置没有改过执行级别，免安装版按**普通用户权限**运行，不会弹 UAC。

---

## 三、分发渠道

- 体积约 **107 MB**：邮件附件通常发不了（多数邮箱上限 25 MB），建议**网盘**或聊天软件的文件传输。
- 只产出 **Windows x64**（NSIS 安装版 + 免安装版）；macOS / Linux 目标未配置。

---

## 四、如果要正式对外发布

唯一的硬伤是**没有代码签名**：

- 首次运行必然出现 SmartScreen「未知发布者」提示，得点"仍要运行"；
- 部分杀毒软件会误报未签名的 Electron 便携包（它本质是 NSIS 自解压）；
- 消除这两点需要购买**代码签名证书**（EV 证书还能立刻获得 SmartScreen 信誉）。

其余已知限制见 `P1-acceptance.md` 的「已知限制」小节。

## 五、自己重新打包

```powershell
cd d:/Mind
npm run dist        # = electron-vite build + electron-builder --win
```

产物在 `release/`：

| 文件 | 说明 |
|---|---|
| `Mind-<版本>-x64-setup.exe` | 安装版（NSIS，可选安装目录、创建快捷方式、带卸载） |
| `Mind-<版本>-x64-portable.exe` | 免安装版（可直接发给别人） |
| `win-unpacked/` | 未打包的目录形态，便于排查问题 |

打包后建议核对（历史上踩过的坑）：

1. **`app.asar` 里必须有 `jszip`** —— 它是被外部化的运行依赖，缺了会**一启动就崩**；
2. 两个 target 的文件名要带 `-setup` / `-portable` 后缀，否则后构建的会覆盖前一个；
3. 发之前先用 `win-unpacked/Mind.exe` 启动一次，确认窗口正常。
